# 🛒 SmartCart Customer Segmentation System

An AI/ML-powered customer segmentation system built using unsupervised learning to help e-commerce platforms understand customer behavior, improve marketing strategies, and increase retention.

---

## 🚀 Problem Statement

SmartCart, a growing e-commerce platform, collected extensive customer data but lacked personalized marketing strategies.  
This resulted in:
- Inefficient marketing campaigns  
- Poor identification of high-value customers  
- Delayed detection of churn-prone users  

---

## 💡 Solution

This project applies **unsupervised machine learning** to group customers into meaningful clusters based on:
- Purchasing behavior  
- Engagement patterns  
- Demographics  

These clusters enable **data-driven decision-making** for targeted marketing and customer retention.

---

## 📊 Dataset Overview

- 📦 **2240+ customers**
- 🧾 **22 features**, including:
  - Demographics (Age, Income, Education)
  - Spending (Wine, Fruits, Meat, etc.)
  - Purchase frequency (Web, Store, Catalog)
  - Engagement (Website visits)
  - Recency & complaints

---

## ⚙️ Features

- 🔍 Data preprocessing & feature engineering  
- 📈 Customer segmentation using clustering algorithms  
- 📊 Visualization of clusters and behavior patterns  
- 🎯 Identification of:
  - High-value customers  
  - Low-engagement users  
  - Churn-risk segments  

---

## 🧠 ML Techniques Used

- K-Means Clustering  
- (Optional) Hierarchical Clustering / DBSCAN  
- Feature Scaling (Standardization)  
- Dimensionality Reduction (PCA)  

---

## 🛠️ Tech Stack

- **Language:** Python  
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn  

---

## 📌 Results

- Successfully segmented customers into meaningful groups  
- Improved understanding of purchasing behavior  
- Enabled targeted marketing strategies  
- Identified potential churn users
